# binary_calculator  
### ホームポジションを中心に2進数で入力する計算機です  

~~*実用性が限りなく低いです*~~  

**; l k j f d s a** の順番に、**1 2 4 8 16 32 64 128**が割り当てられています  
**q w e r** には **+ - * /**　が割り当てられており、  
**:** でUndo、 **Space**で計算結果を式の入力欄に移すことができます  
**z** **x** **c** **v** の順番に、**2 8 10 16進数**の数値を*クリップボードにコピー*します。
**b** キーで終了します  

#### 直接実行するほか、App()クラスをインポート後、binary_calculator_run()メソッドを実行することでも起動できます。その場合、計算結果を返すために、return用のリストに代入してください。

### 引数を付けることで、機能を一部変更できます。  
**太字**:初めからTrueのもの
*  **bi** *2進数を表示します。*
*  **he** *16進数を表示します。*
* oc *8進数を表示します。*
* **explain** *説明を表示します。*
* **clip_slice** *Falseにすると、コピーした数値に接頭辞が付きます。*
